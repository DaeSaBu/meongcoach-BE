API 문서는 테스트를 통과한 스니펫으로부터 생성됩니다.
모듈별로 `== {모듈} API` 섹션을 추가하고, `operation::` 매크로로 스니펫을 포함합니다.

== Auth API

앱이 소셜 제공자 SDK로 로그인해 받은 자격증명을 서버가 검증하고, 우리 서비스의 JWT를 발급합니다.
이후 모든 API는 발급받은 액세스 토큰을 `Authorization: Bearer {accessToken}` 헤더로 전달해 호출합니다.

== Media API

이미지를 서버를 거치지 않고 스토리지(Cloudflare R2)에 직접 업로드하기 위한 API입니다. 액세스 토큰 인증이 필요합니다.

이미지 업로드는 다음 순서로 진행합니다.

1. 업로드 URL 발급 API를 호출해 `uploadUrl`과 `publicUrl`을 받습니다.
2. `uploadUrl`로 이미지를 HTTP `PUT` 합니다. 이때 `Content-Type` 헤더는 발급 요청에 보낸 값과 같아야 합니다.
3. 업로드가 성공하면 `publicUrl`을 온보딩 완료 등 후속 API 요청에 담아 등록합니다.

=== 이미지 업로드 URL 발급

operation::media/image-upload-url[snippets='http-request,request-fields,http-response,response-fields']

==== 실패 응답

operation::media/image-upload-url-error[snippets='http-response,response-fields']

== Onboarding API

로그인 후 온보딩이 필요한 사용자가 프로필과 강아지를 등록하는 API입니다.
두 엔드포인트 모두 액세스 토큰 인증이 필요합니다.

=== 온보딩 메타데이터 조회

온보딩 화면에 필요한 토픽·강아지 성격·MBTI 목록을 한 번에 반환합니다.

operation::onboarding/metadata[snippets='http-request,http-response,response-fields']

=== 온보딩 완료

사용자 프로필과 강아지들을 하나의 트랜잭션으로 생성합니다.
이미 온보딩을 완료한 회원이 다시 호출하면 409를 반환합니다.

operation::onboarding/complete[snippets='http-request,request-fields,http-response,response-fields']

==== 실패 응답

operation::onboarding/complete-error[snippets='http-response,response-fields']
