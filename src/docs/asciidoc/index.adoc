API 문서는 테스트를 통과한 스니펫으로부터 생성됩니다.
모듈별로 `== {모듈} API` 섹션을 추가하고, `operation::` 매크로로 스니펫을 포함합니다.

// == User API
//
// === 회원 가입
//
// operation::user/register[snippets='http-request,path-parameters,request-fields,http-response,response-fields']

== 공통 에러 응답

모든 에러 응답은 RFC 9457 Problem Details 형식(`application/problem+json`)을 따릅니다.

=== 기본 형식

operation::shared/error[snippets='http-response,response-fields']

=== 입력값 검증 실패

operation::shared/error-validation[snippets='http-response,response-fields']

=== 헬스체크
