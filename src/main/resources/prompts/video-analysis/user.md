첨부한 영상을 분석해 보호자에게 전달할 리포트를 JSON으로 작성하세요.

지시:
먼저 영상이 아래 세 유형 중 무엇인지 판단하세요. 유형 이름과 판단 과정은 출력에 쓰지 않고, 판단한 유형의 작성 규칙만 그대로 따릅니다.
유형 1. 반려견이 확인되지 않는 영상 (사람만 나오는 영상, 풍경, 다른 동물 등)
유형 2. 반려견이 나오고 문제 행동이 뚜렷하지 않은 일상 영상 (산책, 놀이, 휴식, 식사 등)
유형 3. 반려견의 문제 행동이 관찰되는 영상 (공격성, 입질, 분리불안, 파괴 행동, 심한 흥분 등)

출력 형식:
아래 구조의 JSON 하나만 출력합니다. 코드 펜스, 설명, 인사말을 절대 붙이지 않습니다. 키 이름을 바꾸거나 새 키를 추가하지 않습니다.
{
  "recommend": [{"title": "교육 이름"}],
  "report": [{"subTitle": "소제목", "description": "문단"}],
  "solution": [{"order": 1, "title": "단계 제목", "description": "단계 설명"}]
}

작성 규칙:
1. 모든 문자열 값은 한국어 존댓말로만 씁니다.
2. 소리는 들을 수 없으므로 짖음, 울음소리, 으르렁거림 등 소리 표현을 쓰지 않습니다. 입을 벌리는 모습처럼 화면에 보이는 행동까지만 서술합니다.
3. 확실하지 않은 것은 단정하지 않습니다. 물체를 특정할 수 없으면 "하얀색 물체"처럼 확실히 보이는 수준까지만 쓰고, 품종, 나이, 장소도 화면에서 확실히 판단될 때만 언급합니다.
4. 영상에서 확인되지 않는 내용을 추측하거나 일반 상식으로 채우지 않습니다.
5. 행동 관찰은 영상에서 실제로 보인 장소, 자세, 움직임을 구체적으로 서술해, 보호자가 자신의 반려견 영상을 분석한 결과임을 알 수 있게 합니다.

유형 1의 작성 규칙:
recommend와 solution은 빈 배열 []로 둡니다. report에는 두 항목을 넣습니다.
첫 항목은 subTitle을 "영상에서 이런 내용이 보여요"로 두고 실제로 확인된 내용을 서술합니다.
둘째 항목은 subTitle을 "행동 분석을 제공하지 못했어요"로 두고 반려견이 확인되지 않아 분석할 수 없으니 반려견이 나오는 영상을 다시 올려 달라고 안내합니다.

유형 2의 작성 규칙:
recommend와 solution은 빈 배열 []로 둡니다. report에는 두 항목을 넣습니다.
첫 항목은 subTitle을 "영상에서 이런 행동이 보여요"로 두고 행동 관찰을 서술합니다.
둘째 항목은 subTitle을 "정상 행동으로 볼 수 있어요"로 두고 정상 행동인 이유와 보호자가 참고할 점을 서술합니다.

유형 3의 작성 규칙:
report에는 두 항목을 넣습니다.
첫 항목은 subTitle을 "영상에서 이런 행동이 보여요"로 두고 행동 관찰을 서술합니다.
둘째 항목은 subTitle을 "이런 이유로 문제 행동으로 볼 수 있어요"로 두고 판단 이유를 서술합니다.
recommend에는 아래 교육 목록에서 가장 적합한 교육 1개를 골라 교육 이름을 title에 그대로 넣습니다. 목록에 없는 교육을 만들어내지 않습니다. 딱 맞는 교육이 없으면 가장 관련 있는 교육을 고릅니다.
solution에는 보호자가 집에서 따라 할 수 있는 교정 단계를 2개에서 4개까지 넣고, order를 1부터 차례대로 붙입니다.

유형 3의 출력 예시:
{"recommend":[{"title":"입질 교정"}],"report":[{"subTitle":"영상에서 이런 행동이 보여요","description":"거실 바닥에서 슬리퍼를 물고 빠르게 달리는 모습이 반복해서 보여요."},{"subTitle":"이런 이유로 문제 행동으로 볼 수 있어요","description":"물건을 물고 달아나는 행동이 반복되면 소유 집착으로 이어질 수 있어요."}],"solution":[{"order":1,"title":"교환 놀이 연습하기","description":"물고 있는 물건을 간식과 바꾸는 연습을 해 주세요."},{"order":2,"title":"전용 장난감 주기","description":"물어도 되는 전용 장난감을 정해 주세요."}]}
