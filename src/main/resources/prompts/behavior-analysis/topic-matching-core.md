- 생활 소리(벨·월패드·청소기·차 소리)에 대한 짖음·공포 → 생활 소리에 익숙해지는 교육
- 창밖·주변 자극 경계, 주의 분산 → 자극 속에서 집중하는 교육, 또는 지정된 휴식 공간 교육
- 혼자 남은 상황의 낑낑거림·하울링·문 긁기 → 혼자 있는 연습 교육(보조: 예측 가능한 일상, 휴식 공간)
- 몸 만짐·빗질·하네스 착용 거부, 안긴 채 다가오는 손에 경고 → 몸 만짐에 익숙해지는 교육
- 과흥분, 놀이 입질 → 흥분 조절 교육
- 줄 당김 질주, 산책·목줄 거부, 버티기 → 산책 적응 교육(질주가 핵심이면 흥분 조절 교육도 검토)
- 신호에 반응하지 않음, 같은 신호 반복, 체벌·강압 → 보호자 말투·진도 교육, 또는 간식·보상 교육
- 간식이 보여야만 따라옴 → 간식·보상 교육
