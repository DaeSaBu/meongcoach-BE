# 공식 기관 기준 견종 조사 목록

확인일: **2026-10-10 (한국 시간)**. 기존 경쟁 앱 추출 자료를 사용하지 않고 공개된 공식 목록을 새로 수집했다.

## 조사 범위와 집계

“모든 견종”은 아래 세 기관의 지정 목록에 있는 **모든 항목**을 의미한다. 미등록 지역견, 역사적으로 사라진 견종, 모든 교잡 조합까지 포함하는 전 세계 단일 목록은 아니다. 정식 인정·잠정 인정·등록 준비 상태를 한 단계로 취급하지 않는다.

| 기준 | 원본 항목 수 | 구분 |
|---|---:|---|
| [FCI 정식·잠정 견종 목록](https://www.fci.be/en/nomenclature/) | 364 | 정식 344, 잠정 20 |
| [AKC 전체 견종 목록](https://www.akc.org/dog-breeds/) | 297 | 정식 그룹 208, Miscellaneous 13, FSS 76 |
| [영국 Royal Kennel Club 견종 표준](https://www.royalkennelclub.com/breedstandards) | 226 | 공개 표준 225, 잠정 표준 1 |
| 통합 카탈로그 | **393** | FCI 364개를 기준으로 기관별 이름·변종을 대응하고 추가 29개를 보존 |
| FCI 상위 변종 행 | 124 | 크기·모질·색상 등. 별도 견종 수가 아님 |
| FCI 하위 변종 묶음 | 35 | 원본의 색상·모질 묶음을 그대로 보존 |

각 기관의 “항목 수”는 이 조사에서 읽은 목록의 행 수다. AKC의 푸들 세 크기 등 별도 항목이 포함되므로 기관이 발표하는 총 인정 견종 수와 같다고 가정하지 않는다. [AKC 인정 연도 표](https://www.akc.org/press-center/articles-resources/facts-and-stats/breeds-year-recognized/)는 갱신일이 다른 자료이므로, 이번 집계는 전체 목록과 상세 페이지의 그룹을 기준으로 한다.

## 파일과 데이터 사용

- [breeds.json](breeds.json): 한글 가나다순 통합 목록과 원본 기관 항목 887개, 기관별 인정 상태, 변종, 별칭, 대응 근거 링크.
- [sources.md](sources.md): 수집·대조·링크 확인에 사용한 모든 출처를 클릭할 수 있는 목록.
- [sources.json](sources.json): URL, 최종 이동 URL, HTTP 상태, UTC 확인 시각, 응답 SHA-256과 접근 실패한 국내 참고 사이트. 본문·사진은 복제하지 않았다.
- [validation.json](validation.json): 원본 목록 대조와 데이터 무결성 점검 결과.

`breeds`는 통합 항목이고 `registry_entries`는 기관의 실제 목록 항목이다. 기관별 화면 선택지를 만들 때는 `registry_entries`의 `listed_name`과 `matches`를 함께 사용한다. 포메라니안처럼 한 기관에서는 독립 항목이고 FCI에서는 변종인 항목이 상위 견종에 가려지지 않도록 해야 한다.

`FCI_###` 식별자는 FCI 표준번호, 추가 항목의 `AKC_...`는 AKC 목록의 영문명에서 만든 조사용 식별자다. 현재 앱의 enum 코드와 일치하지 않으며 API·DB에 바로 넣는 코드가 아니다. `registry_entry_ids`를 따라가면 별칭의 출처를 확인할 수 있다. `recognition_date_original`은 원문 날짜 문자열이며 ISO 날짜로 해석하지 않는다. `subvariety_groups`는 원본의 묶음 표현이므로 묶음 하나를 개별 견종으로 집계하지 않는다.

### 한글명

**이번 파일의 한글명은 편집 음역·번역이며 공식 한글명 확인은 미완료다.** 한국애견연맹 목록은 HTTP 403·시간 초과로 확인할 수 없었다. 따라서 모든 항목에 `name_ko_basis: editorial_transliteration`과 빈 `name_ko_source_urls`를 기록했다. 원어·영문명과 견종의 목록 포함 여부는 공식 자료에서 확인했으며, 확인하지 못한 한글 표기를 공식 기관의 표기라고 주장하지 않는다. 앱에 적용하기 전 국내 표기 검수를 권장한다.

### 중복·변종 처리

- FCI 표준번호가 있는 견종을 기준으로 동일 이름·원어명·공식 별칭을 대응했다. 59개 AKC 항목은 상세 페이지가 연결한 FCI 표준번호로 교차 확인했다. 이름 유사도만으로 자동 통합하지 않았다.
- 벨지안 셰퍼드 네 항목, 푸들 크기, 포메라니안·키스혼드, 파피용, 치와와 모질, 닥스훈트 크기·모질 등은 `match_type: variety`로 상위 견종에 연결했다. 기관별 이름을 유지한다.
- AKC `Collie`와 `Pyrenean Shepherd`는 각각 두 FCI 견종을 포괄하므로 `broader_registry_entry`로 양쪽에 연결했다. 두 FCI 견종 자체를 합치지 않았다. 근거: [AKC Collie](https://www.akc.org/dog-breeds/collie/), [AKC Pyrenean Shepherd 설명](https://www.akc.org/expert-advice/lifestyle/fun-facts-pyrenean-shepherd/).
- AKC `Segugio Italiano`는 상세 페이지가 직접 연결한 [FCI 337 단모종 표준](https://www.fci.be/Nomenclature/Standards/337g06-en.pdf)에 대응했다. FCI 198 거친모종으로 중복 연결하지 않았다.
- AKC·영국의 `Akita`는 FCI American Akita, `Japanese Akitainu`·`Japanese Akita Inu`는 FCI Akita에 대응했다. 근거: [AKC가 인정하는 일본 아키타 견종 클럽의 등록명 설명](https://akita-inu.com/how-to-identify-a-japanese-akita/).
- AKC `Manchester Terrier (Toy)`는 [영국 기관의 미국 명칭 설명](https://www.royalkennelclub.com/search/breeds-a-to-z/breeds/toy/english-toy-terrier-black-tan/)을 근거로 FCI English Toy Terrier에 연결했다. 표준 내용까지 동일하다는 뜻은 아니다.
- FCI 변종 행은 상위 견종의 `varieties` 안에 저장하고 `parent_breed_id`를 명시했다. 이름 없는 원본 변종 행은 선택지로 생성하지 않고 해당 견종에 검토 메모를 남겼다. 크기·모질·색상의 모든 조합을 임의로 생성하지 않았다.

### 검토가 남은 기관 간 대응

| 항목 | 처리와 근거 |
|---|---|
| Anatolian Shepherd Dog ↔ Kangal | 별도 보존. [AKC의 기원 설명](https://www.akc.org/expert-advice/dog-breeds/anatolian-shepherd-dog-history/)과 [영국 Anatolian 표준](https://www.royalkennelclub.com/breed-standards/pastoral/anatolian-shepherd-dog/), [영국 Turkish Kangal 표준](https://www.royalkennelclub.com/breed-standards/pastoral/turkish-kangal-dog/)을 비교하면 기관별 범위가 달라 일괄 동의어로 처리하기 어렵다. |
| Working Kelpie ↔ Australian Kelpie | 별도 보존. [AKC 공식 그룹 목록](https://www.akc.org/public-education/resources/general-tips-information/dog-breeds-sorted-groups/)과 두 상세 페이지가 별도 항목으로 제공한다. 동일 항목으로 합치지 않는다. |

393개는 이러한 기관별 항목 보존 원칙을 적용한 **카탈로그 수**이며, 전 세계에서 생물학적으로 서로 다른 순종이 정확히 393개라는 주장이나 모든 기관의 공통 인정 수가 아니다.

### 믹스견·미상과 기존 앱

믹스견·미상은 이 공식 견종 집계에 넣지 않았다. 앱에서는 별도 선택지 `MIXED`·미상 정책으로 추가할 수 있다. 골든두들·말티푸 등 임의 교잡 조합도 이번 세 기관의 지정 목록에 없으면 추가하지 않았다. 기존 `Breed` enum, API, DB는 수정하지 않았다.

## 수집과 검증

FCI 영문 페이지의 10개 그룹 및 잠정 목록을 수집하고 알파벳별 26개 목록과 표준번호 집합을 대조했다. AKC는 전체 선택 목록과 25개 페이지의 견종 URL 집합을 대조했다. 영국 기관은 표준 목록의 텍스트가 있는 견종 링크를 수집하고 중복 링크·빈 장식 링크·일반 안내 링크를 제외했다. 세 기관의 모든 견종 상세·표준 페이지를 읽어 분류를 확인했다.

FCI 목록·AKC 상세 페이지가 제공하는 표준 문서 링크도 확인했다. AKC가 연결하는 공식 견종 클럽·원산국 등록기관·문서 저장소의 표준은 해당 AKC 페이지를 출처 경로로 함께 남겼다. 원문의 HTTP 표준 링크는 같은 호스트·경로의 HTTPS 링크로 정규화했다. 응답 SHA-256은 조사 시 응답의 식별용이며 원본 본문 백업을 대신하지 않는다. 목록이 갱신되면 확인일과 함께 재조사해야 한다.

견종 목록·상세 페이지는 모두 HTTP 200으로 확인했다. Calupoh의 원산국 표준 PDF 1개는 HTTP 403으로 본문 확인이 제한되어 해당 기관 항목에 표시했다. AKC 원본 표준 링크 값에 포함된 뒤쪽 공백 때문에 실패한 5건은 공백을 제거한 링크로 해결했고 최초 실패 기록도 출처 파일에 보존했다. 최종 검증 수치와 접근 실패 링크는 [validation.json](validation.json)을 기준으로 한다. 원본 목록 포함 여부와 링크 접근 여부는 검증했지만, 국내 공식 한글명 검수와 위 두 기관 간 대응 검토는 완료된 것으로 표시하지 않는다.
